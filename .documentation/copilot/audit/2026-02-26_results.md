### Critical Security Issues

#### SEC-CRIT1: Plaintext Password Validation

**File**: `TriviaSpark.Api/Services/EfCore/EfCoreUserService.cs:115-123`

```csharp
// CURRENT (BROKEN): Compares BCrypt hash with plaintext — will NEVER match
return user.Password == password;
```

**Impact**: User authentication is fundamentally broken. Passwords hashed with BCrypt on creation (via `EfCoreAdminService.cs:53`) can never match via `==` comparison.

**Required Fix**:
```csharp
return BCrypt.Net.BCrypt.Verify(password, user.Password);
```

#### SEC-CRIT2: Plaintext Password Change

**File**: `TriviaSpark.Api/Services/EfCore/EfCoreUserService.cs:126-141`

```csharp
// CURRENT (BROKEN): Plaintext comparison and storage
if (user.Password != currentPassword)  // Won't work with BCrypt hashes
    return false;
user.Password = newPassword;  // Stores plaintext
```

**Required Fix**:
```csharp
if (!BCrypt.Net.BCrypt.Verify(currentPassword, user.Password))
    return false;
user.Password = BCrypt.Net.BCrypt.HashPassword(newPassword);
```
